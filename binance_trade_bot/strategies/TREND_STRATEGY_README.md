# 趋势跟踪策略 (Trend Strategy)

## 概述

这是一个基于市场趋势分析的自动交易策略，通过多维度分析判断币种的看涨/看跌趋势，并据此做出交易决策。

## 核心理念

1. **判断市场趋势**：看涨(BULLISH) / 看跌(BEARISH) / 震荡(NEUTRAL)
2. **看涨时**：持有或买入更强势的币种
3. **看跌时**：卖出并持有USDT避险
4. **震荡时**：保持当前状态或小幅调仓

## 分析维度

策略通过三个维度综合评估市场情绪，得出0-100的分数：

### 1. 价格趋势分析 (权重: 40%)

- 计算价格变化率
- 检测连续上涨/下跌趋势
- 评分标准：
  - 涨幅 > 10%: 90分 (大幅上涨)
  - 涨幅 5-10%: 75分 (中等上涨)
  - 涨幅 2-5%: 65分 (温和上涨)
  - 横盘 ±2%: 50分 (中性)
  - 跌幅 2-5%: 35分 (温和下跌)
  - 跌幅 5-10%: 25分 (中等下跌)
  - 跌幅 > 10%: 10分 (大幅下跌)

### 2. 动量分析 (权重: 30%)

- 计算价格变化的加速度
- 对比前半段和后半段的涨跌幅
- 评分标准：
  - 动量 > 5%: 90分 (加速上涨)
  - 动量 2-5%: 70分 (上涨加速)
  - 动量 ±2%: 50分 (平稳)
  - 动量 -2 to -5%: 30分 (下跌加速)
  - 动量 < -5%: 10分 (加速下跌)

### 3. 价格位置分析 (权重: 30%)

- 计算当前价格在区间中的位置
- 评分标准：
  - 位置 ≥ 80%: 75分 (接近高点，可能继续上涨)
  - 位置 60-80%: 65分 (中高位)
  - 位置 40-60%: 50分 (中间位置)
  - 位置 20-40%: 35分 (中低位)
  - 位置 < 20%: 60分 (接近低点，可能反弹)

## 趋势判断

综合得分后判断趋势：

- **BULLISH (看涨)**: 分数 ≥ 60 (默认)
- **BEARISH (看跌)**: 分数 ≤ 40 (默认)
- **NEUTRAL (震荡)**: 40 < 分数 < 60

## 交易决策逻辑

### 持有USDT时
- 扫描所有币种，寻找看涨信号
- 只在强烈看涨时买入 (分数 ≥ 70)
- 选择分数最高的币种

### 持有其他币种时

#### 看跌信号
- 立即卖出，转为USDT避险

#### 看涨信号
- 保持持仓
- 如果发现更强的币种（分数高出15+），则切换

#### 震荡信号
- 保持观望
- 可以切换到更强的币种

## 配置参数

在 `user.cfg` 中添加以下配置：

```ini
# Trend strategy configuration
# 趋势分析窗口（小时）
trend_window_hours=12

# 看涨阈值：分数 >= 此值表示看涨
bullish_threshold=60.0

# 看跌阈值：分数 <= 此值表示看跌
bearish_threshold=40.0
```

## 使用方法

1. 在 `user.cfg` 中设置策略：
```ini
strategy=trend
```

2. 配置趋势参数（可选，使用默认值即可）

3. 启动机器人：
```bash
python -m binance_trade_bot
```

## 参数调优建议

### 保守型
```ini
trend_window_hours=24      # 使用更长的时间窗口
bullish_threshold=70.0     # 更高的看涨阈值
bearish_threshold=30.0     # 更低的看跌阈值
```
- 优点：减少交易频率，避免假信号
- 缺点：可能错过一些机会

### 激进型
```ini
trend_window_hours=6       # 使用更短的时间窗口
bullish_threshold=55.0     # 更低的看涨阈值
bearish_threshold=45.0     # 更高的看跌阈值
```
- 优点：更快响应市场变化
- 缺点：交易频率增加，手续费成本更高

### 平衡型（推荐）
```ini
trend_window_hours=12      # 默认值
bullish_threshold=60.0     # 默认值
bearish_threshold=40.0     # 默认值
```

## 优势

✅ **趋势跟踪**：顺应市场趋势，不逆势交易  
✅ **风险控制**：看跌时自动转USDT避险  
✅ **多维分析**：综合价格、动量、位置三个维度  
✅ **减少频繁交易**：需要明显信号才切换  
✅ **适应市场**：牛市积极参与，熊市保守防守  

## 风险提示

⚠️ 本策略基于历史价格数据，无法预测未来  
⚠️ 加密货币市场波动大，存在亏损风险  
⚠️ 建议先用小资金测试  
⚠️ 定期监控机器人运行状态
